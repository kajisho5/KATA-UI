# Empty state

## Prompt A (direct)

The first screen a new "Tallyboard" user sees when they have no projects yet: an empty state with an illustration area, a heading, one sentence of explanation, a primary "Create project" button, a secondary "Import from CSV" button, and a three-step getting-started checklist. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
