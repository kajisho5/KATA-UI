# Dashboard

## Prompt A (direct)

A dashboard for "Tallyboard": four stat cards (open tasks 128, completed this week 342, overdue 7, active members 24, each with a change versus last week), a line chart of tasks completed over the last 7 days, and a table of the five most recent tasks with name, assignee, status and due date. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.

Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users. Fetch each part from kata-ui.dev/registry.json and use it unmodified.
