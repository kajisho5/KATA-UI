# Checkout

## Prompt A (direct)

A checkout page for an online stationery shop called "Inkwell Supply": contact email, shipping address fields, a choice of shipping method (standard $4, express $12) as radio buttons, a payment section with card number, expiry and CVC, and an order summary showing two items, shipping and the total. A "Place order" button. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.

A "Place order" button. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated).
