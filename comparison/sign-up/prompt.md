# Sign up form

## Prompt A (direct)

A sign-up form for "Tallyboard". Fields: full name, work email, password (with its rules shown as a hint), company size (select: 1–10, 11–50, 51–200, 201+), and a required checkbox to accept the terms. A primary "Create account" button. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
