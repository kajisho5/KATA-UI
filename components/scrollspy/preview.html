Installation

Load the tokens once, then copy the part. Nothing in the catalog needs a build step, a framework or a package manager — the files are the product.

Tokens

Every color, radius and motion curve is a custom property. Parts read the tokens; they never name a color of their own, which is what makes themes a one-file change.

Parts

A part is a folder: the markup, the CSS, and the small script if it has one. The page for each part shows all three, ready to copy.

Blocks

Blocks are parts already assembled — a login, a pricing table, an app shell. Take the whole block, then take it apart with the catalog.

Themes

A theme moves the accent only. Neutrals, spacing and the vermillion core never change, so a rebrand cannot quietly become a redesign.
