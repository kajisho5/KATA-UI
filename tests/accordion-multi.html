accordion — three independent sets

Set 1

Is there a build step?
No. Copy the CSS, paste the markup. This accordion itself runs on native details — there is no script on this page for it.
Does it work in dark mode?
Yes. Every color comes from a token, and the token set has a dark theme.
Can I change the radius?
Change --k-radius-lg once and every component follows. That is the point of the mold.
