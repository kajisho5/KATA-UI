# 日本語ドキュメント（10部品） 詳細設計書（案）

作成：2026-11-07　対象：kajisho5/KATA-UI　状態：**確認待ち**

## 1. 何を作るか（要件）

ROADMAP Phase 2「Write Japanese documentation for the ten most-used components」を作ります。

- 対象の10部品：Button, Input, Field, Textarea, Select, Checkbox, Radio, Switch, Modal, Dropdown
  - オーナー決定（2026-11-07）：利用者がまだいないので、使われ方のデータはない。T4 の「よくある部品」の上から10個にする。
- 部品ごとに、日本語のページ `/ja/components/<部品>/` を1枚作ります。
- ページに載せるもの：
  - 日本語の説明
  - 使いどころ
  - 導入の手順
  - アクセシビリティ（障害のある人も使えるようにする工夫）
  - 動く見本
  - コード（英語版と同じもの）
- 英語版の部品ページに「日本語」へのリンクを付けます。日本語版には「English」へのリンクを付けます。
- `/ja/` のトップに「日本語ドキュメント」の一覧（10部品）を足します。

### 1-1. 英語版とずれないための決まり

- 日本語の文は、英語版の meta.json（description・usage・a11y）を訳したものです。
- 訳したときの英語の文の「指紋」（ハッシュ値）を、日本語のデータに一緒に残します。
- 英語の文が変わったのに日本語が直っていなければ、テストが落ちます。これで、片方だけ古くなるのを防ぎます。
- コードと動く見本は、英語版と同じファイル（preview.html・CSS・JS）から作ります。日本語用のコピーは作りません。

### 1-2. やらないこと

- 残り126部品の翻訳、ブロック・テンプレートの翻訳
- サイトの共通部分（メニュー・左の一覧・検索）の日本語化
- registry.json・llms.txt・MCP への日本語の追加（必要なら別の PR で提案します）

## 2. 技術選定

既存の build.py（Python）で HTML を作ります。新しい技術・ライブラリは使いません（既存リポの技術は変えないため、比較表は作っていません）。

文字の扱いは、今の `/ja/` ページに合わせます。
- フォント：サイト共通の指定のまま。日本語は端末の標準フォントで表示します。
- 行の高さ：1.8

## 3. 画面構成（`/ja/components/button/` の例、画像 `ja-docs.svg` 参照）

1. パンくず：「日本語ドキュメント / フォームと入力 / Button」
2. 見出し：「Button」＋小さく「ボタン」、状態バッジ（Stable／Beta、英語版と同じ）、右上に「English」へのリンク
3. 説明（1〜2文）
4. 動く見本とコード（英語版と同じ部品。Desktop／Mobile、Light／Dark の切り替えもそのまま）
5. 「導入」：CLI のコマンド1行と、手動の3手順（tokens.css → CSS → HTML）
6. 「使いどころ」：usage の訳
7. 「アクセシビリティ」：a11y の訳。キーボード操作の表（キー／動き）を付けられる部品には付けます
8. 「英語版にだけあるもの」：静的チェック結果、構造（Anatomy）、読むトークン、関連部品。英語版へのリンクで案内します
9. ページの下：「この訳は英語版の◯年◯月◯日の内容をもとにしています」

左の一覧（サイト共通）はそのまま残し、上に「日本語ドキュメント」の10項目を足します。

## 4. 部品の分け方

| ファイル | 役割 |
|---|---|
| `ja/components/<部品>.json` | 日本語の文（name_ja, description, usage, a11y, keys）と、元の英語の文の指紋 |
| `build.py` | `ja_component_page()` を足し、10ページを作る。英語版ページに「日本語」リンクを足す |
| `tests/test_ja_docs.py` | 10部品すべてにデータがあるか。指紋が今の英語の文と合っているか。ページにコードと見本が出ているか |

## 5. 状態管理

新しい動きはありません。見本の切り替え（Desktop／Mobile、Light／Dark）は、英語版の部品ページと同じスクリプトを使います。

## 6. データ構造（例）

```json
{
  "slug": "button",
  "name_ja": "ボタン",
  "source": {"date": "2026-11-07", "sha1": {"description": "…", "usage": "…", "a11y": "…"}},
  "description": "主な操作・もう一つの操作・削除などの操作に使うボタン。無効と読み込み中の見本付き。",
  "usage": "…",
  "a11y": "…",
  "keys": [["Tab", "ボタンへ移動"], ["Enter / Space", "押す"]]
}
```
