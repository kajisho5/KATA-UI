KATA UI（https://kata-ui.dev ）は、フレームワークもビルドも使わない UI 部品集です。部品のコード（HTML・CSS・必要なものだけ JavaScript）をコピーして、自分のプロジェクトに貼って使います。貼ったあとのコードは自分のものです。

## 中身

- 部品 137 個、組み合わせたブロック 21 個、ページの雛形 7 個
- アイコン 150 個、ブランドのロゴ 220 個
- すべて MIT ライセンス
- React などの前提はありません。`<link>` と `<script>` で読み込めば動きます

色・角丸・動きの長さなどは、`tokens.css` という1つのファイルにまとめた変数（トークン）からだけ読みます。テーマ編集の画面（Foundry）でトークンを変えると、全部品の見た目がそろって変わります。

## 「型」とチェッカー

名前の KATA は「型」です。部品ごとに決まりを書き（KATA.md）、それを機械で確かめる `check.py` を用意しています。

- 色・影・時間などがトークン以外の値で書かれていないか
- キーボードで選んだときの枠（focus-visible）があるか
- `<button>` に type があるか、入力欄に名前があるか
- JavaScript の部品が、同じページに複数置いても、2回読み込んでも壊れないか

今のところ 165 個（部品・ブロック・雛形）すべてがこの静的チェックに合格しています。ただし静的チェックはコードを読むだけで、画面読み上げで正しく使えることの証明にはなりません。

そのため「Stable（安定版）」は別の条件にしています。静的チェックに加えて、同じ部品を3つ並べたページ（1つは右から左の言語）でのブラウザテストと、画面読み上げ機能での確認記録がそろったものだけです。今 Stable なのは Button の1つで、残りは Beta です。

## AI に使わせる

部品のデータを AI が読みやすい形でも出しています。

- `registry.json`（shadcn/ui の registry と同じ形式）
- `llms.txt`
- Claude Code などで使える Skill（SKILL.md）
- MCP サーバー

試しに、同じ10画面（ログイン、料金表、ダッシュボードなど）を Claude Code に2通りで作らせて比べました（https://kata-ui.dev/compare/ ）。1つは指示だけで作らせ、もう1つは「KATA UI の部品を registry.json から取って使う」と1文足しました。10画面の合計は次のとおりです。

| 測ったもの | 指示だけ | KATA UI を使用 |
|---|---:|---:|
| 幅 390px・右から左の表示で画面からはみ出した要素 | 43 | 0 |
| ダーク表示で文字が背景と 4.5:1 未満 | 6 | 0 |
| 使われた余白の値の種類 | 130 | 98 |
| ファイルの大きさ（合計） | 109 KB | 287 KB |

ファイルは KATA UI を使ったほうが大きくなりました。部品の CSS をまるごと持ち込むためです。プロンプトと、AI が書いたままのファイルも公開しています。

## 使い方

ターミナルからなら：

```bash
npx @kajisho5/kataui init
npx @kajisho5/kataui add button
```

ターミナルを使わない場合は、各部品のページからコードをコピーしてください。

主な10部品には日本語の説明ページもあります（https://kata-ui.dev/ja/ ）。
