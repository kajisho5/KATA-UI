# Free and Pro: where the line is

Owner decision, 2026-11-07. This file is the reference; the pricing page, README, FAQ and
`/ja/` repeat it.

## Free (MIT)

Everything published through any of these channels is MIT, including every later version
of it:

- this repository (`kajisho5/KATA-UI`)
- `registry.json`, `llms.txt`, the AI Skill and the MCP server
- the CLI (`npx @kajisho5/kataui add …`)
- the pages of kata-ui.dev

As of 2026-11-07 that is 136 components, 21 blocks, 7 templates, 150 icons, 220 brand
marks, the themes and the design tokens. Nothing on this list will be removed from the free
side or relicensed.

## Pro (not on sale yet)

- New blocks and templates written for Pro, delivered outside this repository and the
  public registry.
- Planned price: $129, one payment, every later Pro release included, unlimited projects
  and seats. A founding offer ($99 for the first 100) is described on the pricing page.
- Pro items carry their own license. No Pro item exists yet.

## Rules

1. Nothing moves from Free to Pro. A part, block or template that has been published free
   stays free, and its fixes ship free.
2. A Pro item that is later published to the repository becomes MIT from then on.
3. Copied code keeps the license it was copied under; a pricing change never alters it.

## Why

The README promised that everything in the repository stays MIT, and the 21 blocks and 7
templates were already public in the repository, the registry and the CLI. Selling them
would contradict that promise and could not stop anyone using the MIT copies. ROADMAP Phase 3
also requires that everything already visible stays accessible.
