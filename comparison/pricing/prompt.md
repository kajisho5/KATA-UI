# Pricing

## Prompt A (direct)

A pricing section for "Tallyboard" with three plans: Free ($0), Team ($12 per user per month, marked "Most popular"), and Business ($24 per user per month). Each plan lists four features and has a call-to-action button. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
