# Product Hunt draft

## Name

KATA UI

## Tagline (60 characters max)

Copy-paste UI components in plain HTML, CSS and JS

## Description (260 characters max)

137 components, 21 blocks and 7 page templates with no framework and no build step. Every part reads one tokens.css and passes a static checker. Copy the files or use a one-file CLI. MIT, with a registry, llms.txt and an MCP server for AI tools.

## Topics

Developer Tools, Design Tools, Open Source

## Maker comment

KATA UI is for projects that do not use React: plain HTML pages, server-rendered apps, Astro or Laravel sites. Copy a part's HTML, CSS and (when it has behavior) JS, and it is yours.

One tokens.css holds the colors, radii and motion timing, and the theme editor on the site changes them for every part at once. A static checker in the repository keeps all 165 parts, blocks and templates on those tokens and checks focus rings, button types and repeated script loading.

Only Button is labeled Stable today: Stable also requires a browser test and a recorded screen-reader pass, and the other parts are Beta until they have one.
