# Delete with confirmation

## Prompt A (direct)

A project list for "Tallyboard" with four projects, each with a "Delete" button. Pressing Delete opens a confirmation dialog that names the project and offers "Cancel" and "Delete project". Confirming removes the row and shows a short notification that the project was deleted. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
