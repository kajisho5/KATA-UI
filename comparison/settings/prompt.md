# Settings

## Prompt A (direct)

An account settings page for "Tallyboard" with three groups: Profile (display name, email), Notifications (three on/off switches: email digests, mentions, weekly report), and Appearance (theme select: system, light, dark). A "Save changes" button that shows a confirmation message after it is pressed. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.

An account settings page for "Tallyboard" with three groups: Profile (display name, email), Notifications (three on/off switches: email digests, mentions, weekly report), and Appearance (theme select: system, light, dark). A "Save changes" button that shows a confirmation message after it is pressed. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users. Fetch each part from kata-ui.dev/registry.json and use it unmodified.
