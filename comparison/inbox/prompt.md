# Inbox

## Prompt A (direct)

An inbox screen for a support tool called "Helpline": a left column listing eight conversations (sender, subject, one-line preview, time, unread state), and a right pane showing the selected conversation with its messages and a reply box with a "Send" button. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.

Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users. Fetch each part from kata-ui.dev/registry.json and use it unmodified.
