# Data table

## Prompt A (direct)

A tasks table for "Tallyboard" with 12 rows and columns: task, assignee, status, priority, due date. Columns sort when their header is clicked. A text filter above the table narrows the rows, a count shows how many rows match, and pagination shows 5 rows per page. Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
