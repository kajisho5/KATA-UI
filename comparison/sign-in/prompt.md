# Sign in

## Prompt A (direct)

A sign-in page for a project-management web app called "Tallyboard". Email and password fields, a "Remember me" checkbox, a "Forgot password?" link, a primary "Sign in" button, and a link to create an account. Show an inline error under the password field reading "Incorrect password." Write one complete, self-contained HTML file (inline all CSS and JavaScript; no external requests except where stated). It should work in a current desktop and mobile browser, in light and dark mode, and for keyboard users.
